<h1 align="center"> 👩‍💻Decentralized VFC Verification Costumer for Banks👩‍💻 </h1>



This project presents a decentralized VFC (Verification Costumer) system using blockchain technology, aimed at improving the effectiveness, transparency, and security of customer identity verification across various banks.



## Problematic



Traditional VFC methods have problems like being slow, repetitive, and expensive. Customers have to go through the VFC process each time they deal with a different bank, which can be frustrating and cause delays. Banks also face higher costs and longer processing times.


## Key Challenges in Traditional VFC

**Variation in Specifications:** Each bank has its own VFC procedure, forcing customers to complete VFC several times.

**Customer Experience:** The absence of standardization makes the process lengthy and susceptible to mistakes.

**Costs and Time:** VFC-related costs raise customer onboarding expenses and lengthen processing times more then a month.







## Blockchain Solution

Blockchain technology provides a shared, unchangeable record that all participating banks can access. This approach makes sure VFC data is verified, safely stored, and available to every bank in the network, cutting down on repeated work and boosting security.

### Advantages of Blockchain-Based VFC:

- **Unchangeable Records:** Keeps data accurate and prevents tampering.

- **Shared Data:** All banks see the same customer information, so there’s no need for repeated VFC checks.

- **Faster Verification:** Banks can work together to check customer data, speeding up the process and lowering costs.

- **Better Transparency and Security:** Improves tracking and oversight of VFC processes, helping to spot and prevent fraud.

#### Phase 1: Setting Up VFC:

- ***Adding Customer Data:*** Banks enter customer details into the blockchain network.
- ***Updating Information:*** Banks can change customer details on the network.
- ***Viewing Data:*** Banks can see the customer information stored on the blockchain.

#### Phase 2: Improved Admin and Bank Features

- ***Admin Controls:*** Admins can monitor, approve, and block banks from doing VFC checks.
- ***VFC Request Voting:*** Banks can submit VFC requests for new customers, and other banks can vote to accept or reject the data.
- ***Customer VFC Status:*** The status of VFC is decided by the number of votes for or against the data.
- ***Bank Ratings:*** Banks are rated based on their VFC activities, with dishonest banks being flagged and limited.

#### Phase 3: Private Network Launch

- ***Smart Contract Setup:*** The smart contract is set up on a private Ethereum network.
- ***Bank Participation:*** Banks need an account on the private network to use the smart contract.
- ***Full System Use:*** The decentralized VFC system is fully running on the private network, with all banks involved in the VFC process.


## Technical Implementation

- Blockchain Framework: Ethereum is used to set up the decentralized VFC process, with smart contracts managing the tasks.

- Smart Contracts: Set the rules for adding, updating, and checking customer data, along with voting and admin tasks.

- Private Network: The system runs on a private Ethereum network, keeping data private and controlled among the participating banks.


## How to Run the Project

1. **Install and Set Up:**
   - Run `npm install` to get the necessary packages.
   - Compile the smart contracts with `truffle compile`.
   - Deploy the contracts using `truffle migrate`.
   - Start the application with `npm start`.

2. **Interact with the Network:**
   - Use the web interface or API to work with the decentralized VFC system. Banks can add, update, view customer data, and vote.

3. **Conclusion:**
   - This project shows a scalable, secure, and efficient way to handle VFC verification using blockchain technology. By decentralizing the process, banks can cut down on repetitive work, improve the customer experience, and reduce risks linked to traditional VFC methods.

4. **Future Improvements:**
   - **Integration with National Identity Systems:** Improve VFC verification by linking with government identity databases.
   - **AI-Based Risk Assessment:** Use AI to analyze customer data and provide real-time risk scores.
   - **Interoperability with Other Financial Institutions:** Expand the VFC network to include other financial institutions for a more complete financial ecosystem.
